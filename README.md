💊 MediTrack

A full-stack web application for medication tracking and reminders, designed to help users manage their medicines, track medication intake, monitor adherence, and stay aware of upcoming doses and refills.

🎯 Problem

Managing medicines regularly can be challenging, especially when doses are missed or medicines need to be refilled. MediTrack was designed to make medication management more organized by bringing medicine tracking, reminders, adherence monitoring, and refill information into one application.

✨ Key Features

- 💊 Add and manage medicines
- 📋 View medicine schedules and intake status
- ✅ Track taken, missed, and pending doses
- ⏰ Medication reminders
- 📊 Medication adherence tracking
- 🔄 Medicine refill tracking
- 📈 Medication activity dashboard
- 📅 Medication history and upcoming doses
- 🔔 Reminder and notification functionality

🛠️ Technologies Used

- Frontend: Next.js, React, TypeScript, JavaScript, Tailwind CSS
- Backend: Node.js
- Database: MongoDB
- ODM: Mongoose
- APIs: REST APIs
- Tools: VS Code, Git, GitHub
